# 🌟 About

AdaptAble is an AI-powered accessibility platform built to help **Persons with Disabilities (PwDs)** and **Neurodivergent Individuals** communicate with confidence in workplaces, educational institutions, and everyday life.

The platform provides personalized AI coaching, workplace simulations, sign language assistance, and accessibility-first experiences that adapt to every user's communication style instead of comparing them to conventional standards.

# 💡 Why AdaptAble?

Communication barriers often prevent talented individuals from reaching their full potential.

AdaptAble creates a safe AI-powered environment where users can practice conversations, improve communication skills, and build confidence before facing real-world situations.

# 🚀 Getting Started

### Clone the repository

```bash
git clone https://github.com/mohamedfaiyaz777/AdaptAble.git
cd AdaptAble
```

### Install dependencies

```bash
npm install
```

### Configure Environment Variables

Create a `.env.local` file.

```env
GEMINI_API_KEY=YOUR_GEMINI_API_KEY
```

### Run the application

```bash
npm run dev
```
